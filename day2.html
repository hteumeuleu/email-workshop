Responsive

aka “Start on desktop and use media queries for mobile.”

Media Queries

<style>
	@media only screen and (max-width:600px) {
		.foo {
			background:red;
		}
	}
</style>
<div class="foo">
	Lorem ipsum dolor, sit amet.
</div>

Breakpoints

/* Mobiles */
@media only screen and (max-width:480px) {
}

/* Tablets */
@media only screen and (min-width:481px) and (max-width:767px) {
}

/* Desktop */
@media only screen and (min-width:768px) {
}

👉 Base your breakpoints on your content (not on devices sizes).

Two useful utility classes

  1. .mobile-block { display:block; }
  2. .mobile-width { width:100%; }
